# Rod Rempel for Anmore Council

Campaign website for Rod Rempel, candidate for Anmore Village Council in the 2026 general local election.

## Preview locally

Open `index.html` in a browser, or run any local static server from this directory.

## Deploy

This is a dependency-free static site. Import the repository into Vercel and deploy with no build command. The output directory is the repository root.

## Before public launch

- Confirm the campaign email address in `index.html`.
- Replace the financial-agent placeholder with the exact authorization statement required by Elections BC.
- Confirm all voting locations and advance-voting dates against the Village of Anmore election page.
- Add approved social links if the campaign creates official accounts.
- Complete candidate and financial-agent approval of all campaign claims.
